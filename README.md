# 开放实验室 · 平板触控优化版

第一人称 3D 教室。左边是电学自由台，右边是制氧实验。

平板和手机：左侧摇杆移动，右侧滑动转头，右边的按钮用于跳跃、冲刺和进入实验台。控制设置提供小、标准、大三种触控尺寸。

电脑：WASD 移动、鼠标转头、空格跳跃、Shift 或双击 W 冲刺、C 下蹲。走近后点击桌面或按 E 进入实验。

实验运行文件来自固定版次的[电学实验](https://github.com/yulong3327-dotcom/oxygen-lab-3d/tree/4b5c67d0aa65113d78ac34f8db82a918fdf7bdb2)和[制氧实验](https://github.com/yulong3327-dotcom/oxygen-lab-3d/tree/79c3f8fe9d6742225d34ecf16ea062b8b370de42)。
